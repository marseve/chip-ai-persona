# Chip Reference Images

Drop Chip’s official reference images here.

## How to upload (no code needed)

1. On GitHub, open this folder (`docs/images/chip`).
2. Click **Add file → Upload files** and drag your images in.
3. Click **Commit changes**.
4. Add a row for each image in the [Visual Reference](../../chip/visual-reference.md) table.

## Naming

`chip-<version>-<what-it-is>.png`, all lowercase with dashes. For example:

- `chip-v3-front.png`
- `chip-v3-turnaround.png`
- `chip-v3-systems-art.png`
- `chip-v3-expressions.png`

Old looks stay here too. Just mark them 🗄 Retired in the Visual Reference table instead of deleting them.
